What you can expect

Five promises.

  • We start with your processBefore any code we sit with your team and write down how the work moves today.
  • Progress you can clickWork is reviewed in functioning software at each step, so surprises show up early and cheaply.
  • Someone you can nameFor every deliverable you know who to call.
  • Built to be handed overSource, deployment steps and documentation come with the project. Your next developer can pick it up.
  • Testing that fits the stakesA brochure site and a payments system do not need the same checks. We decide together how much testing is enough.
Straight talk

When you should not hire us.

Being clear about this saves both of us time.

  • If a spreadsheet and a shared checklist solve your problem, we will say so.
  • If an existing product fits, we will point you to it rather than build something new.
  • If a request is unclear, we will ask questions before quoting, not after.

Not sure if we are the right fit?

Tell us the problem. If we are not the right team, we will say so.
